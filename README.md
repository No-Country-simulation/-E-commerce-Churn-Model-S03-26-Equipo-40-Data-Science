# E-commerce Churn Predictor: Online Retail II

## 📌 Descripción del Proyecto
Este repositorio contiene el desarrollo de un modelo predictivo diseñado para identificar la probabilidad de abandono (Churn) de clientes . El objetivo principal es transformar datos transaccionales en insights accionables que permitan reducir el costo de adquisición y maximizar el valor de vida del cliente.

## 🛠️ Stack Tecnológico
* **Lenguaje:** Python
* **Entorno:** Google Colab / Jupyter Notebooks
* **Librerías:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Base de Datos:** Supabase (PostgreSQL)
* **Visualización:** Power BI

## 📊 Metodología y Estado Actual
El proyecto se encuentra en la **Fase de EDA y Feature Engineering**. 

### Hitos alcanzados:
1.  **Ingesta y Limpieza:** Procesamiento del dataset *Online Retail II* (UK), eliminando ruidos transaccionales y gestionando devoluciones/cancelaciones.
2.  **Definición de Negocio:** Establecimiento del umbral de Churn en **90 días de inactividad**.
3.  **Construcción de la Tabla Maestra:** Generación de métricas **RFM** (Recency, Frequency, Monetary) por cada `CustomerID`.
